# NinjaCookBook

Україномовна інтерактивна книга рецептів у форматі PWA (Progressive Web App) для мультиварки **Ninja Foodi SmartLid OL650EU**. Працює офлайн, встановлюється на телефон чи комп'ютер і не потребує реєстрації.

> ⚠️ **Застереження.** Застосунок не замінює офіційну інструкцію до мультиварки. Перед готуванням під тиском завжди перевіряйте за інструкцією мінімальний рівень рідини (не менше 250 мл), лінію PRESSURE MAX, правило «не більше половини чаші» для рису та продуктів, що набухають, і положення клапана (SEAL / VENT). Кроки з позначкою «Перевірте за інструкцією» містять дані, які не підтверджені інструкцією.

## Можливості

- Головна сторінка: пошук (за назвою, інгредієнтом, тегом, категорією), картки категорій, блоки «Обрані рецепти» та «Нещодавно переглянуті».
- Сторінка рецепта:
  - час і кількість порцій;
  - перемикач порцій з автоматичним перерахунком інгредієнтів;
  - список інгредієнтів, у якому можна позначати вже підготовлене;
  - покрокова інструкція з окремим блоком параметрів мультиварки (режим, тиск або рівень, час, клапан);
  - поради;
  - кнопка «Додати в обране».
- Світла й темна теми. За замовчуванням береться системна тема, вибір запам'ятовується.
- Кнопка «Не вимикати екран» (Screen Wake Lock API) у браузерах, які її підтримують.
- Власні рецепти: кнопка «Додати рецепт». Вони зберігаються лише в цьому браузері, а всі їхні кроки позначаються «Перевірте за інструкцією».
- Повна робота з клавіатури, видимий фокус, `prefers-reduced-motion`, кнопки щонайменше 44×44 px.
- Офлайн-режим після першого відкриття.

## Структура

```
NinjaCookBook/
├── index.html              # розмітка всіх екранів
├── manifest.json           # Web App Manifest (відносні шляхи)
├── service-worker.js       # офлайн-кеш (CACHE_VERSION)
├── css/styles.css
├── js/
│   ├── app.js              # точка входу: маршрутизація (#/, #/recipe/<id>, #/category/<id>), SW
│   ├── data.js             # завантаження та нормалізація data/recipes.json
│   ├── storage.js          # localStorage: обране, нещодавні, тема, позначки, власні рецепти
│   ├── theme.js, theme-init.js
│   ├── components.js       # картки, порожні стани
│   ├── add-recipe.js       # форма «Додати рецепт»
│   ├── wakelock.js
│   ├── utils.js
│   └── views/home.js, views/recipe.js
├── data/recipes.json       # база рецептів
├── icons/                  # icon.svg, icon-maskable.svg, icon-192.png, icon-512.png, icon-maskable-512.png
├── images/                 # SVG-ілюстрації рецептів і заглушка
└── docs/                   # вихідні матеріали (інструкція OL650EU, таблиця режимів, рецепт). Не змінювати!
```

Збирати нічого не потрібно. Node.js і сторонні бібліотеки не використовуються.

## Запуск локально

ES-модулі та Service Worker **не працюють через `file://`**, тому застосунок треба відкривати через локальний вебсервер.

**Варіант 1. Python** (з кореня репозиторію):

```powershell
python -m http.server 8000
```

Відкрийте <http://localhost:8000/>.

**Варіант 2. VS Code + Live Server.** Встановіть розширення Live Server і натисніть **Go Live** у рядку стану.

**Перевірка роботи з підшляху** (як на GitHub Pages). Запустіть сервер із **батьківської** папки й відкрийте `http://localhost:8000/NinjaCookBook/`:

```powershell
cd ..
python -m http.server 8000
```

> Якщо після змін бачите стару версію, у DevTools → Application → Service Workers натисніть **Unregister** (або увімкніть **Update on reload**) і оновіть сторінку.

## Як додати рецепт

Рецепти зберігаються у файлі [`data/recipes.json`](data/recipes.json). Щоб додати рецепт:

1. Додайте об'єкт у масив `recipes` за схемою нижче. `id` має бути унікальним, латиницею, без пробілів (наприклад, `"borshch"`), бо він потрапляє в адресу `#/recipe/borshch`.
2. Технічні дані (режим, тиск, температура, час) беріть **лише** з інструкції в `docs/` або з перевіреного рецепта. Якщо параметр не підтверджено, поставте в кроці `"verified": false`. Застосунок покаже позначку «Перевірте за інструкцією».
3. За бажанням додайте SVG-ілюстрацію в `images/` і вкажіть відносний шлях у полі `image`. Чужі фото використовувати не можна.
4. Збільште `CACHE_VERSION` у `service-worker.js` (див. нижче). Якщо додали нові файли, допишіть їх у `APP_SHELL`.
5. Перевірте JSON на коректність, наприклад так: `python -m json.tool data/recipes.json`.

### Схема `data/recipes.json` (`schemaVersion: 1`)

```json
{
  "schemaVersion": 1,
  "device": "OL650EU",
  "categories": [{ "id": "main", "name": "Основні страви", "icon": "🍲" }],
  "recipes": [{
    "id": "plov",
    "title": "Плов",
    "category": "main",
    "description": "Короткий опис",
    "servings": 5,
    "prepMinutes": null,
    "cookMinutes": 80,
    "difficulty": null,
    "tags": ["свинина", "рис"],
    "ingredients": [
      { "name": "Рис", "amount": 500, "unit": "г", "note": "промити" },
      { "name": "Олія", "amount": 80, "amountMax": 100, "unit": "мл", "note": null },
      { "name": "Спеції", "amount": null, "unit": null, "note": null }
    ],
    "steps": [{
      "stage": "Етап 1. …",
      "text": "Що зробити",
      "mode": "Pressure Cook",
      "temperature": null,
      "pressure": "High (Hi)",
      "minutes": 20,
      "minutesMax": null,
      "valve": "SEAL",
      "note": "Додаткове пояснення",
      "verified": true
    }],
    "tips": ["Порада"],
    "image": "images/plov.svg"
  }]
}
```

| Поле | Опис |
|---|---|
| `categories[].id / name / icon` | Категорія. Категорії без рецептів показуються з позначкою «Скоро». |
| `servings` | Базова кількість порцій, від неї рахується перерахунок. `null` вимикає перемикач порцій. |
| `prepMinutes`, `cookMinutes` | Хвилини або `null`, якщо невідомо. |
| `difficulty` | `"easy"`, `"medium"`, `"hard"` або `null`. |
| `ingredients[].amount` / `amountMax` | Число або діапазон (`amountMax`). `null` означає «за смаком», таке не перераховується. Для `шт.` і `головка` округлення до ½. |
| `steps[].stage` | Необов'язкова назва етапу, кроки групуються за нею. |
| `steps[].mode` | Назва режиму з інструкції: `Pressure Cook`, `Sear/Sauté`, `Steam`, `Slow Cook`, `Air Fry`, `Steam Air Fry`, `Steam Bake`, `Steam Bread`, `Steam Meals`, `Grill`, `Bake`, `Dehydrate`, `Yogurt`; для скидання тиску — `Natural Release`. `null` означає крок без мультиварки. |
| `steps[].pressure` | Для `Pressure Cook`: `High (Hi)` або `Low (LO)`. |
| `steps[].temperature` | Температура в °C або рівень Sear/Sauté (`Lo 1` … `Hi 5`). |
| `steps[].minutes` / `minutesMax` | Час кроку або діапазон. |
| `steps[].valve` | `SEAL` або `VENT`. |
| `steps[].verified` | `false` вмикає позначку «Перевірте за інструкцією». |

Якщо змінюєте схему (нові обов'язкові поля, інша структура), збільште `schemaVersion`, оновіть `SUPPORTED_SCHEMA_VERSION` у `js/data.js` і цей розділ README.

## Оновлення версії кешу Service Worker

Service Worker кешує застосунок для офлайн-роботи. Після **будь-якої** зміни HTML, CSS, JS, іконок, зображень або `recipes.json`:

1. Відкрийте `service-worker.js` і збільште версію: `const CACHE_VERSION = 'v3';` → `'v4'`.
2. Якщо додали або перейменували файл, оновіть список `APP_SHELL`.
3. Опублікуйте зміни. Під час активації нової версії старі кеші видаляються автоматично. Користувачі отримають оновлення після наступного відкриття застосунку, іноді для цього потрібно двічі перезавантажити сторінку.

## Публікація на GitHub Pages

1. Закомітьте й запуште зміни в гілку `main`.
2. На GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, гілка `main`, папка `/ (root)`.
3. За хвилину-дві застосунок буде доступний за адресою `https://<ім'я-користувача>.github.io/NinjaCookBook/`.

Усі шляхи в проєкті відносні, тому застосунок працює як з підшляху, так і з кореня домену.

## Встановлення на телефон

- **Android (Chrome / Edge):** відкрийте сайт, у меню **⋮** виберіть **«Встановити застосунок»** або **«Додати на головний екран»**.
- **iPhone / iPad (Safari):** відкрийте сайт, натисніть **Поділитися** → **«На початковий екран»**.
- **Windows / macOS (Chrome / Edge):** значок встановлення в адресному рядку.

Після першого відкриття застосунок працює без інтернету.

## Відомі обмеження

- Обране, нещодавні, тема, позначки інгредієнтів і власні рецепти зберігаються в `localStorage` **лише на цьому пристрої й у цьому браузері**. Синхронізації немає. Якщо очистити дані сайту, вони зникнуть.
- Перерахунок порцій змінює лише список інгредієнтів. Кількість води й час у кроках наведено для базової кількості порцій. Збільшуючи кількість, стежте за лінією PRESSURE MAX і правилом «рис — не більше половини чаші».
- Час готування не враховує час набору тиску («PrE») і тривалість природного скидання понад вказане в рецепті.
- Screen Wake Lock підтримується не всіма браузерами (зокрема, старими версіями Safari). Там, де його немає, кнопка не показується.
- У Safari на iOS офлайн-кеш може бути очищений системою, якщо застосунком довго не користуватися.
